# Tawfiq AI — extracted, not part of Nelavista

These files were originally mixed into the Nelavista template directory but are actually a
separate product ("Tawfiq AI", an Islamic-studies AI companion), sharing no routes, models, or
business logic with Nelavista. None of them were ever wired into a live Flask route in this app.

They're kept here (outside `templates/`, so Flask can't serve them even by accident) in case
Tawfiq AI is maintained as its own project going forward, rather than being deleted outright.
If Tawfiq isn't being continued, this whole directory can be safely removed.
